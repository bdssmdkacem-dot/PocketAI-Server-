# PocketAI Server

Local AI server for Android: Flutter UI + Android native layer + llama.cpp + GGUF + OpenAI-compatible LAN API.

## MVP 0.1
- Android arm64 target
- Flutter dashboard
- Native Android integration boundary
- GGUF model directory
- OpenAI-compatible API contract
- GitHub Actions release APK

Models are not bundled in the APK.
